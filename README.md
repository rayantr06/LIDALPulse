# RamyPulse / LIDAL Pulse

Prototype de veille marketing multilingue pour les marques algériennes. Le dépôt réunit une API Python/FastAPI, une interface React/TypeScript et des modules de traitement et d'analyse des avis.

## Démonstration et prise en main

La démonstration ProtoMarket permet de parcourir **Surveiller → Comprendre → Agir** avec une base générée localement à partir de données synthétiques.

1. **[Installer et lancer la démonstration sur Windows](https://github.com/rayantr06/ramypulse/blob/179ce489f43c0effc6af028ab7940d0e66acafd1/docs/protomarket_ii_2026/INSTALLATION_DEMO_POUR_EQUIPE.md)** : prérequis, préparation, lancement, arrêt et dépannage pour un membre de l'équipe.
2. **[Préparer la captation et la narration](https://github.com/rayantr06/ramypulse/blob/179ce489f43c0effc6af028ab7940d0e66acafd1/docs/protomarket_ii_2026/VIDEO_LIDAL_PULSE_PROTO_MARKET_2026.md)** : parcours et scénario de démonstration d'environ deux minutes, avec les précautions de présentation. Ce document est un script de narration, pas une vidéo enregistrée.

Ces liens sont figés au commit `179ce489f43c0effc6af028ab7940d0e66acafd1` de la branche **`codex/lidal-pulse-compact-dashboard`**, proposée dans la **[PR #3](https://github.com/rayantr06/ramypulse/pull/3)**. Les guides et scripts de cette démonstration ne sont pas encore dans `main` au moment de la rédaction : suivez la branche indiquée dans le guide d'installation.

## Branches et statut

- **`main`** : base historique du projet.
- **`codex/lidal-pulse-compact-dashboard`** : démonstration ProtoMarket décrite par les deux guides ci-dessus.
- **`codex/lidal-pulse-v3`** : travail V3 distinct, proposé dans la **[PR #4](https://github.com/rayantr06/ramypulse/pull/4)**. Le guide ProtoMarket ci-dessus n'est pas un guide d'installation de la V3.

Le projet reste un prototype. Les données de la démonstration sont synthétiques; elles ne représentent pas des résultats commerciaux réels. La démonstration ne prouve ni le déploiement du futur SLM, ni une mise en production, ni l'existence d'un client payant.
